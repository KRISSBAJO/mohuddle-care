# Milestone care imagery

Four additional original scenes are saved as `care-art.png`, `care-kitchen.png`,
`care-team.png` and `care-family.png`. The complete final prompt set and generation
method for these assets are in `new-care-scenes.json`. They appear in the landing
page gallery and careers feature, careers opportunities, and both application cards.

Created with the built-in ImageGen tool. The subjects are fictional illustrations, not actual Milestone clients or staff. The public hero identifies the imagery as illustrative. Next.js optimizes these local source assets for delivery.
