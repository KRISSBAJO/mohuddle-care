# Mohuddle mobile identity

`mohuddle-icon-v2.png` is the camera-free folded M app icon, splash image and sign-in mark.
The green, ivory and lime artwork was created with the built-in image generation tool,
using the user-supplied rounded M screenshot as a style reference. It contains no camera symbol.
The PNG is square and opaque for the app icon; Expo renders native density variants during prebuild.
Keep the source image at full resolution.

Prompt used: Create a premium square Mohuddle app icon inspired by the reference's rounded,
dimensional folded ribbon M. Use a full-bleed forest-green #173e35 background, with the M
shifting from warm ivory to soft lime #dcef98, subtle fold shading and soft highlights.
Center the M with generous safe padding. Remove the camera entirely; no secondary symbol,
text, badge, frame or surrounding screenshot. Keep it legible at small sizes.
